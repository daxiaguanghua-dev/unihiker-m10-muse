# Muse Linux SDK provenance

`linux/` is a snapshot based on [`facebookincubator/muse-gadget-sdk`](https://github.com/facebookincubator/muse-gadget-sdk) at upstream commit `812c46f9fe42b69d916613a9dc702cbac5ff7b54`. The project added M10-specific display, hardware, voice, and live connection-status code to the Linux SDK. This directory is included so the interface's dependency is inspectable; it should not be confused with an unmodified upstream release.

The upstream project is licensed under Apache-2.0. Its license is preserved in [`LICENSE`](LICENSE). For original installation and pairing guidance, use the [upstream Linux README](https://github.com/facebookincubator/muse-gadget-sdk/blob/main/linux/README.md); the M10 integration in this repository still needs fresh-board deployment testing.
